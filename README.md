# Pyzer — python in your browser

---

## Features

- Runs real Python in your browser, no install or server needed.
- Supports matplotlib, And other library from micropip
- Built with plain HTML, CSS, and JavaScript files. 
- Deployed on Vercel
- Modern Material 3 Expressive design that looks clean and polished.
- Material Symbols Rounded icons for a soft, consistent look.
- Google Sans Flex font for expressive, readable text.
- Design tokens for colors and typography, so retheming takes one change.
- Custom purple theme with light and dark modes. 
- Option to download your python file

## Features in progress ⏱️:
- option to  change font to poppins
--- 
## ⚠️Known limitations:
- download your code before refreshing the page.
- Startup takes around 30 to 40 seconds once

## Tech stack

Built on plain html, CSS, and JavaScript with pyodide as Running engine for the interpreter.

---
## Files

| Files             | Purpose                                              |
| ----------------- | ---------------------------------------------------- |
| index.html        | Main files for markup and base                       |
| index.css         | Styling                                              |
| index.js          | Core functionally of app                             |
| pyodide-worker.js | Runs pyodide                                         |
| sw.js             | Service worker that caches files for faster retrival |
| icons/*           | Holds all icons for favicon                          |
