# PpPad — An online python compiler
official site: pypad-bay.vercel.app
---
## Features:
- Built with beautiful material 3 expressive design 
- *Recently added*: separate layouts for desktop and mobile devices
- Some quick snippets for quick python testing
- Syntax hilighting, brackets and paired symbols auto complete, auto indentation and every basic things that an editor should have
- Dark and light mode support
- Includes all modules supported by skulpt
- Option to download your python file

## Features in progress ⏱️:
- option to  change font to poppins
- trying to clean up code base  
--- 
## ⚠️Known limitations:
- Not all libraries are supported
- download your code before reloading your browser.
